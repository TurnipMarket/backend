COMO PROBARLO
  1. Definí las variables de entorno SMTP_HOST, SMTP_USER, SMTP_PASSWORD y JWT_SECRET (mínimo 32 caracteres).
  2. pip install -r requirements.txt   (ojo: ese archivo trae paquetes del sistema que conviene sacar)
  3. python -m pytest tests -q         -> resultado esperado: 39 passed
  4. uvicorn main:app --host 0.0.0.0 --port 5000 --reload

OJO CON LA BASE VIEJA

  y volvé a levantarlo (se crea de nuevo; se pierden los datos de prueba).
  El PRAGMA de claves foráneas funciona con cualquier base.
